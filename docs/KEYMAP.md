# Eyelash Sofle Keymap

This document outlines the 4-layer keymap for the Eyelash Sofle, featuring homerow mods and dedicated layers for navigation, system controls, and a numpad.

## Homerow Mods

Homerow mods are implemented using ZMK's `behavior-hold-tap`. This allows a key to perform one action when tapped and another when held. In this keymap, the homerow keys are configured as follows:

- **Tap:** Standard letter (e.g., `A`)
- **Hold:** Modifier key (e.g., `Left GUI`)

This enables quick access to common modifiers without leaving the home row, improving typing ergonomics and reducing hand movement.

- `A` (hold): `LGUI`
- `S` (hold): `LALT`
- `D` (hold): `LSFT`
- `F` (hold): `LCTL`
- `J` (hold): `RCTL`
- `K` (hold): `RSFT`
- `L` (hold): `RALT`
- `;` (hold): `RGUI`

## Layers

### Layer 0: BASE (QWERTY)

Standard typing layer with homerow mods.

```
,-----------------------------------------.                    ,-----------------------------------------.
| ESC  |  1   |  2   |  3   |  4   |  5   |                    |  6   |  7   |  8   |  9   |  0   | Bksp |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
| Tab  |  Q   |  W   |  E   |  R   |  T   |                    |  Y   |  U   |  I   |  O   |  P   |  \   |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
| Caps |A/GUI |S/ALT |D/SFT |F/CTL |  G   |-------.    ,-------|  H   |J/CTL |K/SFT |L/ALT | ;/GUI|  '   |
|------+------+------+------+------+------|       |    |       |------+------+------+------+------+------|
|LShift|  Z   |  X   |  C   |  V   |  B   |-------|    |-------|  N   |  M   |  ,   |  .   |  /   | Enter|
`-----------------------------------------/       /    \       \-----------------------------------------'
            | LCTRL| LGUI | LALT | MO(1)| Space|Enter | /--------\ |Enter |Space | MO(2)|RShift| Delete|
            `----------------------------------'       `--------' `----------------------------------'
```

### Layer 1: NAV (Navigation & Media)

For mouse movement, scrolling, and media keys. Access via `MO(1)`.

```
,-----------------------------------------.                    ,-----------------------------------------.
|  `   |  F1  |  F2  |  F3  |  F4  |  F5  |                    |  F6  |  F7  |  F8  |  F9  | F10  |      |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|      |  `   | LCLK | MCLK | RCLK | MB4  |                    | PgUp | Home |  Up  | End  |  -   |  =   |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|      |  ~   |      |      |      | MB5  |-------.    ,-------| Left | Down |  Up  |Right |  [   |  ]   |
|------+------+------+------+------+------|       |    |       |------+------+------+------+------+------|
|      | RGB  | RGB  | RGB  | RGB  | RGB  |-------|    |-------| RGB  | RGB  | Ins  | F11  | F12  |      |
`-----------------------------------------/       /    \       \-----------------------------------------'
            |      |      |      |      |      | LCLK | /--------\ |      |      | MO(3)|      |      |
            `----------------------------------'       `--------' `----------------------------------'
```

### Layer 2: SYS (System & Bluetooth)

For system functions like reset, bootloader, and Bluetooth profile switching. Access via `MO(2)`.

```
,-----------------------------------------.                    ,-----------------------------------------.
|  ~   | BT 0 | BT 1 | BT 2 | BT 3 | BT 4 |                    |  F6  |  F7  |  F8  |  F9  | F10  |      |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|      |BT CLR| CLR A|      |      |      |                    |      |      | F11  | F12  |  _   |  +   |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|      |USB_OUT|BLE_OUT|     |      |      |-------.    ,-------|      |      |      |      |  {   |  }   |
|------+------+------+------+------+------|       |    |       |------+------+------+------+------+------|
|      | Reset|      | DFU  |      |      |-------|    |-------|      |      | Reset| Off  | DFU  |      |
`-----------------------------------------/       /    \       \-----------------------------------------'
            |      |      |      |      |      | LCLK | /--------\ |      |      |      |      |      |
            `----------------------------------'       `--------' `----------------------------------'
```

### Layer 3: NUM (Numpad & Symbols)

A full numpad on the right hand and symbols on the left. Access by holding `MO(1)` (NAV) and tapping the `MO(2)` thumb key, which is configured as `MO(3)` on the NAV layer.

```
,-----------------------------------------.                    ,-----------------------------------------.
|  ~   |  F1  |  F2  |  F3  |  F4  |  F5  |                    |  F6  |  F7  |  F8  |  F9  | F10  | Bksp |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|      |  !   |  @   |  #   |  $   |  %   |                    |  *   |  7   |  8   |  9   |  +   | F11  |
|------+------+------+------+------+------|                    |------+------+------+------+------+------|
|      |  [   |  ]   |  {   |  }   |  |   |-------.    ,-------|  /   |  4   |  5   |  6   |  -   | F12  |
|------+------+------+------+------+------|       |    |       |------+------+------+------+------+------|
|      |  \   |  `   |  ~   |  _   |  =   |-------|    |-------|  0   |  1   |  2   |  3   |  .   | Enter|
`-----------------------------------------/       /    \       \-----------------------------------------'
            |      |      |      | MO(1)|      |      | /--------\ |      |      | MO(2)|      |      |
            `----------------------------------'       `--------' `----------------------------------'
```
